# Shared components

Search `src/components/` before building anything. A page that builds its own version of something a component already
does will look a little different from every other page, and drift further each change.

- Change a component in place rather than wrapping it or making a near-copy.
- Ask before adding a new variant, or a new component that overlaps one that exists. Say what the existing ones can't
  do.
- `src/components/ui/` holds shadcn's components on Base UI, adapted here. Add another with
  `pnpm dlx shadcn@latest add <name>`, then give it a story. `src/components/` holds the club's own, built from them.

## Stories are tests

Each component has a `*.stories.tsx` beside it, with made-up sailing data. `mise run test` renders every story in
Chromium twice, light at a laptop's size and dark at a phone's, and runs axe on each. An accessibility violation fails
CI. A story with a `play` function also checks what it does: an overlay story opens the overlay, so axe checks it open.
